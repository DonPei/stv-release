Installing

Windows

Unzip to a folder of your choice (e.g., C:\apps\stv), then double-click the launch script to start.

macOS

Unzip and drag the folder to Applications, or run it in place. Double-click the launch script.

Linux

Unzip, make the launch script executable (chmod +x stv.sh), and run it.

No installer required. Nothing is written outside the folder you unzipped. To uninstall, delete the folder.

System Requirements

OS

64-bit Windows 10+, macOS 11+, or 64-bit Linux.

Display

32-bit color, 1280×800 or better. Widescreen works best.

Memory

Enough to hold your data. A 500-trace × 2000-sample file is only a few MB.
