Seismic Trace Viewer

Look at your SEG-Y data — quickly and honestly. A fast, portable desktop viewer for seismic traces, headers, and amplitudes.

Download STV 1.0.0 Read the Manual

Version 1.0.0 • Windows • macOS • Linux • No Java install required

One Tool, Done Well

STV does not process, filter, or migrate data. It shows you the traces — so you can check that a file is what it claims to be before it goes into processing or interpretation.

Open & Browse

Open a folder of SEG-Y files (.segy, .sgy) and click through them in the file tree. A recent-files list keeps your last 20 files and folders one click away.

Wiggle Display

Every trace drawn as a seismic wiggle. Rasterized rendering keeps panning and zooming smooth, even for large files.

Header Inspection

View the 3200-byte textual header, the 400-byte binary header, and live trace headers that follow your cursor across the display.

Byte Order Control

Traces look like noise? Flip the Big Endian checkbox to reload as little-endian (SEG-Y rev 2.0). Instant, reversible.

Snapshots

Capture the view to the clipboard or a PNG file — with or without side labels — for reports and presentations.

Portable

No installer. No Java to install. Unzip the download and run — on Windows, macOS, or Linux.

SEG-Y, Covered

Revisions 0, 1, and 2.0. Big-endian and little-endian. IBM float, integer, and IEEE sample formats. STV reads the common formats and shows you the headers so you can verify the data yourself.
